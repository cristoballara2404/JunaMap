Antes de salir: el equipaje

Tres cosas y listo. Sin ellas, el tren no parte.

Node.js 20.6+

Trae npm. Revisa con node -v.

Docker Desktop

Levanta PostgreSQL con PostGIS en un comando. Sin Docker, necesitas PostgreSQL 15+ con PostGIS instalado a mano.

Un navegador moderno

Y conexión a internet: el mapa descarga sus teselas de OpenStreetMap.

1

Línea 1 · Instalar

Cinco estaciones. Cada una abre una terminal distinta, así que deja las anteriores corriendo.

  1. Estación Clonar

    Baja el proyecto y entra a la carpeta.

    git clone https://github.com/cristoballara2404/JunaMap.git cd JunaMap

  2. Estación Base de datos

    Copia el archivo de variables, cambia la clave y levanta Docker. Esto crea la base junamap, el esquema y los datos de ejemplo.

    cp .env.example .env # edita POSTGRES_PASSWORD en .env docker compose up -d

    ¿Sin Docker? Crea la base y carga los scripts a mano:

    psql -d junamap -f db/schema.sql psql -d junamap -f db/seed.sql

  3. Estación Servidor

    Copia server/.env.example como .env y completa tres cosas: DATABASE_URL (con la misma clave del paso anterior), JWT_SECRET y, si quieres administrar locales, ADMIN_KEY (vacía = función apagada).

    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
    cd server cp .env.example .env npm install npm start

    Debe aparecer JunaMap API escuchando en http://localhost:3000/api/v1.

  4. Estación Cliente

    En otra terminal:

    cd client npm install npm run dev

  5. Terminal: abrir la app

    Entra a http://localhost:5173. Si ves el mapa con pines, llegaste.

    TipPara comprobar que la lógica está sana: cd server && npm test. Deben pasar las 28 pruebas.
OjoEl archivo .env nunca se sube a GitHub. Contiene tu clave de la base y el secreto de las sesiones.

Línea 2 · Usar la app

Mirar el mapa no pide cuenta. Guardar, pedir y reseñar sí.

  1. Explora el mapa

    El mapa carga los locales de la zona visible: arrastra, acerca o aleja y aparecen los de esa área (hasta 300 por consulta, los más cercanos al centro). Los filtros cambian el orden: Más cerca, Mejor calificados y Menú del día. Los logos son de las cadenas; los locales sin logo muestran una inicial.

  2. Crea tu cuenta

    Toca Ingresar → Crear cuenta. Necesitas correo, contraseña y aceptar la casilla de privacidad. No pedimos RUT, teléfono, tarjeta ni saldo de la beca.

  3. Abre una ficha

    Toca un pin o una tarjeta y luego Ver. Verás el menú, las promos y las reseñas de otros estudiantes. El corazón guarda el local en favoritos.

  4. Deja tu reseña

    Se firma con tu nombre corto y tu carrera, no con tu correo. Solo puedes editar o borrar las tuyas.

  5. Pide con promo

    Pulsa Pedir con promo y luego Confirmar pedido. Recibes un código de retiro (por ejemplo JM-5750). La promo se paga en el local; la app solo cobra el costo de servicio.

  6. Revisa tu perfil

    En Perfil → Mis pedidos verás el pedido «Por retirar». Márcalo con «Ya lo retiré» o «Anular». También puedes cambiar tu operador (Pluxee o Edenred), ver tus favoritos y eliminar tu cuenta con todos tus datos.

  7. ¿Falta un local? Notifícalo

    Con sesión iniciada, el chip + Notificar local abre un formulario: nombre, dirección, categoría y operador. No enviamos tu ubicación. El equipo revisa las sugerencias y las suma al catálogo.

OjoQue una cadena tenga convenio no garantiza que cada sucursal lo acepte. La app no lo afirma: confirma siempre en el buscador oficial de Pluxee o Edenred.

Línea 3 · Datos reales

La base trae solo cuatro locales ficticios. Los reales se cargan aparte y viven en PostgreSQL: si borras el volumen de Docker, hay que volver a cargarlos.

  1. Ver qué hay cargado

    docker compose exec -T db psql -U junamap -d junamap -c "select origen, count(*) from locales group by origen;"

    Si solo aparece demo, faltan los reales.

  2. Listado del equipo (Maipú y Providencia)

    Desde server/:

    node --env-file=.env scripts/importar-csv.js ..\db\locales_junaeb_excel.csv "Listado del equipo"

    Las direcciones ya vienen geocodificadas. Algunas son aproximadas, por calle.

  3. Sucursales de supermercados (OpenStreetMap)

    Una sola vez, agrega las columnas nuevas. Después importa alrededor de unas coordenadas (radio de hasta 1500 m). Necesita internet y a veces los servidores de Overpass se ponen lentos: repite el comando si falla.

    Get-Content db\migracion_osm.sql | docker compose exec -T db psql -U junamap -d junamap cd server node --env-file=.env scripts/importar-osm.js -33.51 -70.76 1500

  4. Locales verificados a mano

    Anota cada local del buscador oficial en db/locales_verificados.csv (nombre, categoría, dirección, horario, lat, lng) y apunta la fecha de verificación.

    node --env-file=.env scripts/importar-csv.js ..\db\locales_verificados.csv "Buscador de Pluxee, 23-11-2026"

  5. Tabla de sugerencias (bases ya existentes)

    Una sola vez, desde la raíz del proyecto:

    Get-Content db\migracion_sugerencias.sql | docker compose exec -T db psql -U junamap -d junamap

    Las sugerencias se ven con GET /api/v1/sugerencias y la cabecera x-admin-key.

  6. Menús de demostración

    node --env-file=.env scripts/cargar-menus-junaeb.js
    OjoEsos menús, precios y promos son ficticios y sirven para mostrar la app. No reflejan los valores ni los topes reales de la beca.

  7. Logos

    Viven en client/public/logos y su índice en client/src/logos.json. Solo se usan logos de marca, nunca fotos. Para regenerarlos: node scripts/descargar-logos.js (necesita internet).

Línea 4 · Día de la demo

Para mostrar la app desde un celular o a otra persona, sin desplegar nada: un túnel temporal de Cloudflare.

  1. Levanta todo

    Docker, servidor y cliente corriendo, y http://localhost:5173 abriendo bien.

  2. Abre el túnel

    En una terminal nueva (instala con winget install Cloudflare.cloudflared si hace falta):

    cloudflared tunnel --url http://localhost:5173

    Aparece una URL https://…trycloudflare.com. Esa es la dirección para compartir.

  3. Ensaya antes

    La URL cambia cada vez que reinicias el túnel. Deja esa terminal abierta durante toda la presentación. Abre la URL desde tu celular con datos móviles, acepta el permiso de ubicación y pide una promo de punta a punta.

OjoEl túnel apunta al cliente (:5173), no a la API. Vite reenvía /api al servidor. Si ves «Blocked request. This host is not allowed», falta allowedHosts: true en client/vite.config.js (solo para la demo).

Colección Postman. docs/junamap.postman_collection.json reúne las peticiones de la demostración técnica. Impórtala y define base = http://localhost:3000/api/v1 y admin_key con el valor de ADMIN_KEY.

Reglas del juego

Lo que JunaMap hace, lo que no hace y lo que declaramos con franqueza.

  • Tu contraseña se guarda solo como hash scrypt con sal. Nunca en claro.
  • Tu ubicación se usa para cada consulta y no se almacena. Si la niegas, el mapa usa un punto del campus.
  • Puedes eliminar tu cuenta desde el perfil: se borran tus reseñas, pedidos, favoritos y sugerencias.
  • Los menús, precios, promos y reseñas de demostración son ficticios.
  • Los logos pertenecen a sus marcas y se usan solo con fines académicos.
  • JunaMap no muestra ni cobra el saldo de la beca.
  • No hay recuperación de contraseña ni verificación del correo.
  • No afirma que un comercio acepte la beca: el convenio de cada sucursal se confirma en el buscador oficial.
